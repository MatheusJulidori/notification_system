# Unified Notification Microservice API

This project is a robust and scalable backend API designed to handle and process notifications asynchronously. It demonstrates the architecture of a distributed system, where different services work together to perform a single task. The API can be integrated into various applications to manage and send notifications such as emails, SMS, or other messages.

-----

## **Technologies & Tools**

  * **Backend:** **NestJS** (Node.js Framework), **TypeScript**
  * **Database:** **PostgreSQL**
  * **ORM:** **TypeORM**
  * **Message Broker:** **RabbitMQ**
  * **In-Memory Store:** **Redis**
  * **Containerization:** **Docker**, **Docker Compose**
  * **Load Balancer:** **Nginx**
  * **Testing:** **Jest**
  * **API Documentation:** **Swagger**
  * **Logging:** **Pino Logger**, **Loki**
  * **Metrics:** **Prometheus**
  * **Obesevability:** **Grafana Dashboard**

-----

### **Key Features**

  * **Secure Authentication:** Utilizes API Keys for secure access.
  * **Asynchronous Processing:** Notifications are queued via RabbitMQ, ensuring non-blocking and efficient processing.
  * **Data Integrity:** Implements database transactions to ensure data consistency during critical operations.
  * **Scalability:** Designed to be easily scaled with multiple instances using Docker and a load balancer.
  * **High Performance:** Incorporates Redis for caching user preferences, reducing database load.
  * **Comprehensive Testing:** Includes a suite of unit and integration tests to guarantee code reliability.
  * **Observability:** Provides health check endpoints and detailed logging and metrics for monitoring the system.

### **Getting Started**

Follow these steps to set up and run the project locally.

#### **Prerequisites**

  * **Docker** and **Docker Compose** must be installed on your machine.
  * **Node.js** and **npm** are required to install dependencies.

#### **Setup**

1.  **Clone the repository:**

    ```bash
    git clone [repository_url]
    cd [repository_folder]
    ```

2.  **Install Node.js dependencies:**

    ```bash
    npm install
    ```

3.  **Configure environment variables:**
    Create a `.env` file based on the provided `.env.example` and fill in the required values for the database, RabbitMQ, and Redis connections.

4.  **Start the services:**
    Use Docker Compose to build and run all the project services (API, PostgreSQL, RabbitMQ, Redis, Nginx).

    ```bash
    docker-compose up --build
    ```

    *If you want to scale the API instances, use a command like `docker-compose up --build --scale api=3`.*

The application will be accessible via `http://localhost:[port]` (as defined in your .env file).

-----

### **API Documentation**

`http://localhost:[port]/api`
